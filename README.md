# 百度官网核验助手

一个 Manifest V3 Chrome 扩展。在 Google 搜索结果旁显示百度针对**当前搜索词 + 当前网址**给出的“官方”标识状态。

## 调研结论

- 截至 2026-09-20，没有查到功能相同、仍可在 Chrome 应用商店获取的扩展。
- 百度公开开发者平台没有提供“输入域名，返回是否官网认证”的公开 API。
- 百度官网认证不是域名的永久布尔属性。百度说明，只有搜索词命中认证词包、且结果 URL 精确匹配时，才会展示“官方”标识。

因此，本扩展不会把“未发现标识”说成“该网站不是官网”。默认模式读取百度搜索结果页；如果百度返回安全验证，则显示“百度核验不可用”。生产使用建议接入有授权、稳定的数据服务。

## 安装

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录 `D:\coding\git_rep\baidu-verify`。
5. 打开 Google 搜索页。每条自然搜索结果的网址右侧会出现核验状态。

当前默认支持：

- `https://www.google.com/search?...`
- `https://www.google.com.hk/search?...`

## 状态含义

- `百度官方`：百度在当前查询结果里对匹配域名展示了“官方”标识。
- `未显示百度官方`：百度结果里找到了该域名，但该结果没有“官方”标识。
- `百度未收录此结果`：当前百度结果页没找到该域名，不能据此判断真伪。
- `百度核验不可用`：百度安全验证、网络错误或页面格式变化导致无法核验。

点击蓝色“百度官方”标签可以打开对应的百度查询页。鼠标停留在任一标签上可查看原因。

## 自定义 API

点击扩展图标，把“核验来源”改为“自定义 JSON API”。扩展会请求该地址：

```http
POST /verify
Content-Type: application/json
Authorization: Bearer <可选 token>

{
  "query": "百度公司",
  "results": [
    { "domain": "baidu.com", "url": "https://www.baidu.com/" }
  ]
}
```

支持按域名返回对象：

```json
{
  "results": {
    "baidu.com": {
      "status": "official",
      "reason": "百度在该关键词下展示官方标识",
      "sourceUrl": "https://www.baidu.com/s?wd=..."
    }
  }
}
```

`status` 可为 `official`、`not_official`、`not_found`、`unavailable`。也可以直接返回布尔值，但对象格式能表达“不确定”和错误状态，更安全。

## 隐私与安全

- 默认模式会把 Google 当前搜索词发送给百度，除此之外不发送数据。
- 自定义 API 模式会向你配置的地址发送搜索词和当前结果的域名/URL。
- 缓存仅保存在 Chrome 本地，6 小时过期；弹窗中可随时清除。
- Bearer Token 只保存在本机 Chrome 存储中，不参与 Chrome 同步。仍不要把百度 Secret Key 或其他长期主密钥放进扩展；应放在你控制的服务端。

## 已知限制

- 百度会对自动请求触发安全验证，默认模式不保证持续可用。
- 百度页面结构变化后，解析器可能需要更新。
- Google 页面结构也可能变化；本扩展目前只处理自然搜索结果。
- 核验结果只代表百度在该搜索词下的展示，不构成安全、法律或主体资质保证。
